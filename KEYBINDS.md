# ⌨️ Onyxshell Keybindings

Comprehensive list of all default keyboard shortcuts and mouse gestures configured in Onyxshell.

> [!TIP]
> - `SUPER` refers to the Windows / Command key.
> - `ALT` refers to the Alt / Option key.
> - Keybindings can be customized in [`~/.config/hypr/lua/keybinds.lua`](file:///home/sadid/onyxshell/.config/hypr/lua/keybinds.lua).

---

## 🚀 Application Launchers & Desktop Navigation

| Keybinding | Action |
| :--- | :--- |
| `SUPER + RETURN` | Open Default Terminal (Kitty) |
| `ALT + SPACE` | **Open Quickshell Application Launcher** |
| `SUPER + Q` | Toggle Dropdown Scratchpad Terminal |
| `SUPER + E` | Open File Manager (Yazi) |
| `SUPER + B` | Launch Default Browser |
| `SUPER + L` | Lock Screen (Hyprlock) |
| `SUPER + M` | Open Power Menu |
| `SUPER + SHIFT + R` | Reload Hyprland & Desktop Shell |
| `SUPER + SHIFT + B` | Toggle Top Bar Visibility |

## 🪟 Window Management

| Keybinding | Action |
| :--- | :--- |
| `SUPER + X` | Close Focused Window |
| `SUPER + SPACE` | Toggle Single Window Floating |
| `SUPER + SHIFT + SPACE` | Toggle All Windows on Workspace Floating |
| `SUPER + F` | Toggle Fullscreen / Maximized |
| `SUPER + \` | Toggle Split Direction |
| `ALT + TAB` | Cycle & Switch Windows (Alt+Tab Switcher) |
| `ALT + SHIFT + TAB` | Cycle Windows Backward |
| `SUPER + G` | Toggle Window Group (Tabbed Mode) |
| `SUPER + ]` / `SUPER + [` | Next / Previous Window in Group |
| `SUPER + Left / Down / Up / Right` | Focus Window (or `SUPER + H / J / K / L`) |
| `SUPER + Left Mouse Click` | Drag / Move Window |
| `SUPER + Right Mouse Click` | Resize Window |

## 🌌 Workspaces & Scratchpad

| Keybinding | Action |
| :--- | :--- |
| `SUPER + 1..9, 0` | Switch to Workspace 1..10 |
| `SUPER + SHIFT + 1..9, 0` | Move Focused Window to Workspace 1..10 |
| `SUPER + TAB` | Switch to Previous Workspace |
| `SUPER + Scroll Up / Down` | Cycle through Workspaces |
| `SUPER + S` | **Toggle Special Workspace (Scratchpad)** |
| `SUPER + CTRL + S` | **Move Window into Special Workspace** |
| `SUPER + CTRL + Y` | **Move Window out of Special Workspace** |
